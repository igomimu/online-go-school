# 本格使用初回の気づき（2026-09-01）

レッスン中は記録のみ行い、修正・調査はレッスン後にまとめて実施する。

## 気づいた点

1. カメラ映像が固まる。対局や講義の動作には問題なし。
2. 生徒リストのマイクとスピーカーのアイコンは、現在と逆にするほうが直感的かもしれない。
   - マイクを押す：先生（私）の音を、その生徒へ届ける。
   - スピーカーをオンにする：その生徒の音を、先生（私）が聞く。
3. カメラ映像の固まりを直すため先生側でリロードしたところ、再接続になった。再接続のラグは大きくなかった。
   - 生徒たちのマイクON設定はOFFに戻った。
   - 生徒たちのカメラON設定は維持された。
4. 中断中の棋譜も、検討盤で開いて検討できるようにしたい。
5. 田尚人さん：対局を中断した後に新規対局を作成すると、講師側には見えるが、生徒側では碁盤が開かない。

## 対応結果

- 1: 映像要素の停止検知と自動再生復旧を追加。次回の実授業で再確認する。
- 2・3: アイコンの意味を講師目線へ統一し、生徒別音声設定を再読込・再接続後も復元するよう修正。
- 4: 中断局の履歴に「検討」と「再開」を別々に表示。
- 5: 中断局を進行中の中央碁盤から外し、新規対局の通知と生徒側自動オープンを補強。実ブラウザE2Eで生徒2画面の新規碁盤表示まで確認。
