## 実測で判明した土台の欠陥（着手の根拠）
1. **Webフォントが1文字も読み込まれていない**
   `index.css` の `@font-face` が `src` に Google Fonts の **CSS の URL** を指定していた。
   @font-face に渡せるのはフォントファイル（woff2 等）のみなので、この宣言は機能しない。
   `index.html` にも `<link>` は無し。Playwright 実測で `document.fonts` が `Inter:error`、
   `h1` は宣言すら存在しない `Outfit` を指定 → **全画面が OS 標準フォントで表示されていた**。
2. **和文フォント指定が存在しない** — スタックは Inter → system-ui のみ。
   CLAUDE.md「日本語UI契約」が禁止する「和文フォント fallback 未指定」に該当。
3. **日本語組版が未設定** — `line-height: 1.5`（和文本文は 1.7〜1.9 が必要）、
   `line-break` / `word-break: auto-phrase` 等の指定なし。
4. **色に意味が割り当てられていない** — blue 42 / red 38 / green 16 / amber 13 / yellow 3 箇所が混在。
   amber と yellow が同一用途で二重化。
5. **半透明レイヤー 93 箇所**（`bg-white/10` 等）— glassmorphism 時代の残骸。
   ソリッド化済みの `.glass-panel` と併存し質感が不統一。
6. ログイン画面が中央揃えのカード 1 枚のみで PC 1440×900 の下 2/3 が空白。
   開発者向けの「データインポート（JSON）」が生徒の初見画面に露出。

## デザイン方針 — 「色は盤上にだけ宿る」
7/23(8) で三村さんが高く評価したのは
「彩度アクセント無しのニュートラルな濃淡で階層を表現」＋「木目・那智黒・蛤の質感を持つ碁盤」。
= **UI は無彩色、色と質感は碁盤だけが持つ** という構成は既に三村さん自身が選んでいる。
今回はその原則を全画面に徹底するだけであり、新しい色の提案ではない。
撤回されたアンバー基調は採用しない。

### タイポグラフィ
- 和文 **Noto Sans JP** 400/500/700、欧文・数字 **Inter**（CLAUDE.md 標準に準拠）
- 本文 line-height 1.8 / 見出し 1.35〜1.45 / フォーム・表は 1.5（本文ルールを継承させない）
- 見出しは和文 700 + `letter-spacing: 0.06em` + `word-break: auto-phrase`
- **時計・手数・目数は `tabular-nums`** — カウントダウンで数字幅が揺れるのを止める

### Signature（この画面だけの一点）
ログイン画面の左に **木目と盤線と星だけの「空の盤の隅」** を置く。石は置かない。
- 石を並べると定石の正誤が問われる（相手は九段）。空盤なら間違いようがなく、
  「これから打つ場所」というログイン画面の意味とも一致する。
- 既存アセット `wood-board-texture-v2.webp` と GoBoard と同じ罫線色を再利用、追加コストなし。
- コピーを「オンライン囲碁指導プラットフォーム」から USP へ差し替え：**「石を置きながら、話せる。」**
  （三村さん本人の言語化「双方向で石を置きながら話すことができる」より）
