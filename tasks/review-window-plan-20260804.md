# 解説（検討）を別ウィンドウにする — 設計メモ（2026-08-04）

## なぜ

三村さんの解説の流れ:

1. 生徒一覧の「履歴」から棋譜を開いて検討を始める
2. その状態のまま、**生徒のマイクの入切・検討への参加・着手権限**を切り替えたい

今は検討画面が `fixed inset-0 z-50` の全面オーバーレイで、教室ホームを覆う。
「開始前に完全に設定できなかった場合に、閉じないと参加者の追加、音声のオンオフなどが
できない」（三村さん）。IGC は検討中でもホーム画面を操作できる。

対局は既に別ウィンドウ方式（`?mode=game`）で、教室ホームを触りながら打てる。
検討も同じ形にする、というのが三村さんの選択（2026-08-04）。

## 引っかかり

対局の別ウィンドウは **Supabase が正本**なので、LiveKit を張らずに済んでいる。
検討の手順は**メモリ上にしかなく、LiveKit の BOARD_UPDATE で生徒へ配っている**。
同じ講師 identity で LiveKit をもう1本張ると衝突するため、別ウィンドウから直接
配信はできない。

## 方針の候補

### 案A: ポータル（同じ JS 文脈のまま、描画先だけ別ウィンドウ）
`window.open('', 'ogs-review')` した空ウィンドウへ `createPortal` で検討UIを描く。

- 利点: 状態も `classroomRef` も本体と同一。中継が要らない。配信のコードは今のまま
- 注意:
  - 開いた側の `<style>` / `<link rel=stylesheet>` を popup の `document.head` へ複製する
    （Vite は dev で `<style>`、本番で `<link>`）
  - `data-theme` を popup の `documentElement` にも当てる
  - **キーボードは popup の window に張り直す**。ReviewBoard は `window.addEventListener`
    を使っており、そのままだと F キーや矢印が効かない
  - popup を閉じたとき・本体が遷移したときの後片付け

### 案B: 別ルート + ウィンドウ間の中継
`?mode=review` の独立インスタンスにし、`BroadcastChannel` で本体と往復する。
本体が LiveKit への送受信を代行する。

- 利点: 対局ウィンドウと同じ「独立ルート」の形。文脈が分かれるぶん壊れ方が読みやすい
- 注意: 手順ツリー（GameNode）はそのまま送れないので、SGF 文字列など送れる形に直す。
  ReviewBoard の `classroomRef` を差し替えられるよう、送信口を interface に切る

**採用: 案A を第一候補**。配信まわりのコードに触らずに済み、退行の幅が狭い。
案A でスタイルの複製が渋いようなら案Bへ切り替える。

## あわせて直すもの

### 1. 「配信先の生徒」が効いていない（不具合）
UI で生徒を選べるが、盤の同期は `classroomRef.current.broadcast()`（全員宛）で
送っており、`sendTo` を使っていない。選んでも全員に配信されている。
→ `targetStudents` が空でなければ `sendTo(msg, targetStudents)` にする。
対象は BOARD_UPDATE / DRAW_UPDATE / DRAW_CLEAR / CURSOR_MOVE / AI_ANALYSIS_UPDATE。

### 2. 生徒の着手権限（新規）
三村さんの選択は「**先生の盤にも反映**」（2026-08-04）。
「ここに打ってみて」と言って盤上で答えさせる使い方。

- 先生が生徒ごとに許可を出す（既定は不許可）
- 許可された生徒の盤は `readOnly` を外す
- 生徒が置いたら `REVIEW_STUDENT_MOVE {x, y}` を先生へ送る（生徒は自分では置かない）
- 先生側で権限を確認（sender identity で照合）してから `addMove` し、
  いつもの BOARD_UPDATE で全員へ返す。**権限の判定は先生側が正本**
- 先生は取り消せる（既存の Delete / Ctrl+Z）
- 権限は `REVIEW_PERMISSIONS {allowed: string[]}` で生徒へ配る

### 3. 生徒ごとの操作列
別ウィンドウ化ができれば、マイク入切は教室ホームの生徒一覧でそのまま行える。
検討ウィンドウ側には「検討への参加」と「着手権限」だけ置けばよい。

## 進め方

1. 「配信先が効いていない」を直す（小さく、単体で価値がある）
2. 着手権限（配信の仕組みは今のまま）
3. 別ウィンドウ化（案A）
4. 生徒ごとの操作列を整理

3 は退行の幅が大きいので、1・2 を先に本番へ入れて確かめてから着手する。
